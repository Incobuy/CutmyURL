# CutmyURL Bot

A professional, high-performance Telegram-based URL shortener service built with Node.js, Telegraf, and SQLite.

## Features
- Custom link aliases (slugs) selection.
- Free tier limit (up to 5 short links per user).
- Premium monetization tier via Telegram Stars ($0.20 per extra link).
- Click tracking and analytics (clicks, device info, geo-tracking).

## Tech Stack
- **Node.js** - Runtime environment.
- **Telegraf** - Telegram Bot Framework.
- **SQLite3** - Lightweight embedded database.
- **Nanoid** - Unique URL slug generator.
